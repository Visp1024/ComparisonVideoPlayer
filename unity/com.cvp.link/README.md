# CVP Link

Запуск отрезка видео в плеере [CVP](../../README.md) из кода Unity.

Отрезок, файлы и выравнивание треков задаются в самом плеере руками — отсюда идут
только команды транспорта.

## Установка

Package Manager → **Add package from git URL**:

```
https://github.com/Visp1024/ComparisonVideoPlayer.git?path=unity/com.cvp.link
```

Или **Add package from disk** — выбрать `unity/com.cvp.link/package.json`.

## Использование

В плеере: кнопка **«Unity»** в верхней панели → включить «Внешнее управление».

```csharp
using Cvp;

CvpPlayer.Play();                  // встать на начало отрезка и играть
CvpPlayer.Play(fromStart: false);  // продолжить с текущей позиции
CvpPlayer.Pause();                 // пауза на месте
CvpPlayer.Stop();                  // пауза и возврат на начало отрезка
CvpPlayer.Rewind();                // встать на начало, не запуская
CvpPlayer.SetLoop(true);           // повторять отрезок

if (CvpPlayer.IsConnected) { /* плеер на связи */ }
```

Вызывать можно откуда угодно — компонент на сцене не нужен, соединение поднимается само
и переподключается после перезапуска плеера. Когда плеера нет, вызовы ничего не делают
и не бросают исключений.

`Window → CVP Link` — окно с состоянием связи и кнопками транспорта: удобно проверить
связь и погонять отрезок без входа в Play Mode.

## Ограничения

- Только Windows. На других платформах пакет компилируется, но команды не отправляются.
- Связь односторонняя: плеер не сообщает ни позицию, ни состояние воспроизведения.
  `IsConnected` обновляется с задержкой до полусекунды.
- Имя канала по умолчанию `cvp`; менять — `CvpPlayer.PipeName` до первой команды и то же
  имя в модалке плеера.
